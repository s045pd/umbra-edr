Proxy CA Certificate

The proxy decrypts HTTPS by signing certs with its own root CA. Your browser will reject HTTPS through the proxy until this CA is trusted by your OS.

1. Download

Saves Umbra-CA.crt from to your Downloads folder.

2. Trust it

Run once in Terminal — adds the cert to the System keychain and marks it trusted:


          
          
Or double-click the downloaded .crt → Keychain Access → find Umbra MITM Root CA → "When using this certificate" → Always Trust.

        


        

          
Run as Administrator (PowerShell):

          

          
          
Or double-click the .crt → Install Certificate → Local Machine → Trusted Root Certification Authorities.

        


        

          
Run with sudo:

          

          
          
Path varies by distro — adjust if your system uses /etc/pki/ca-trust/source/anchors/ instead.

        

      


      

        
3. Verify

        
After trusting, restart your browser and retry the proxy. Visit any HTTPS site through the proxy — it should load without certificate warnings.

        
⚠ Trusting this CA lets the umbra-server server decrypt all your local HTTPS traffic. Only do this on dev machines.
